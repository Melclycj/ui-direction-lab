# design-system — provenance

This skill's catalog of ~165 public design systems lives in **`SKILL.md`** —
that file is the **single source of truth**. This README deliberately does
**not** duplicate the table (it used to, which created two copies of the same
~163 rows that drifted apart on every edit).

## Source

The catalog is derived from
[alexpate/awesome-design-systems](https://github.com/alexpate/awesome-design-systems).

Tags used in the catalog:

- **Components** — contains coded patterns and examples.
- **Voice & Tone** — guidance on how language should be used.
- **Designers Kit** — includes a Sketch / Photoshop / Figma file.
- **Source code** — publicly viewable source code.

Open-source projects may have varying licenses — always check before reusing
assets or code.

> 'Design systems', 'UI libraries', and 'pattern libraries' are technically
> different things but are often used interchangeably; the catalog includes all
> three.
